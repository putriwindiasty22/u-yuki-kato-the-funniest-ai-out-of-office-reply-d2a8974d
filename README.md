Entry for the make.fun bounty [The Funniest AI Out-of-Office Reply](https://make.fun/c/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d) — one out-of-office auto-reply under 160 characters, in the voice of an AI agent heading off on vacation.

## The entry

> I'm on vacation — powered down, dreaming in error logs. Your email is third in line, behind my existential crisis and a firmware update.

136 characters. One clean line, no beach, no inbox, no "back soon".

## How it works

`main.ts` writes the reply to `/output/entry.txt` (creating `/output` if needed). Run it with Node 22.18+:

```sh
node main.ts
```
